# Beginner HTML & CSS Portfolio Projects

This bundle contains three beginner-friendly, static website projects:
1. Personal Portfolio
2. Olive & Oak fictional Restaurant Website
3. FIZUNO fictional Product Landing Page

## How to open
Open each project's `index.html` file in a browser.

## Before publishing
- Review every sentence and make sure it accurately describes your own skills and experience.
- Replace `your.email@example.com` with a professional email address you choose.
- Update the portfolio projects list as you complete and understand each project.
- The restaurant and FIZUNO brands are fictional practice concepts.
- The restaurant hero image and Google Fonts use external internet resources; the pages still work without them, but the appearance may differ offline.

## Learning note
These are AI-assisted starter projects. Study the HTML and CSS, change the content and design yourself, and only present parts you can explain confidently. Do not claim that you independently wrote code you have not yet studied.
